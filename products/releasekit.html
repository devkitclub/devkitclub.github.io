04 / get started

Verify locally first

  1. Prepare the toolkit

    Extract the kit, create a virtual environment, and install its hash-locked dependencies

  2. Try a reference package

    Run validation, then use the installer on a copy of the Python or npm example

  3. Review before publishing

    Adapt the configuration, inspect the dry-run artifacts, and follow the ecosystem guide before enabling a publishing workflow

After download / from the extracted kit
python3 -m venv .venv
# Activate .venv for your shell, then:
python -m pip install --require-hashes -r requirements.lock
python tools/validate.py

05 / compatibility

Check your setup

Python
3.12–3.14 and Git, including when checking npm projects
JavaScript
Node 22.14+, 24, or 26; npm 10+ locally, 11.5.1+ for Trusted Publishing
Package layout
Single-package repositories; pure Python with static setuptools metadata or ESM JavaScript with concrete exports
Scope
No runtime package dependencies in v1; development dependencies must be locked
Publishing
Your own registry accounts and supported GitHub approval gates; hosted publishing checks remain unverified

The current release candidate has local validation evidence. Hosted approval behavior, real registry publishing, and buyer delivery still need verification
